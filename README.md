# 概要

[【電子書籍ライブラリ Mica】](https://pumicebimsstein.github.io/Mica/)は、各サイトの電子書籍情報を集約して管理するためのウェブアプリケーションです。画像をクリックして読書ページへ飛ぶように設定することが可能です。

※ 本当はJSONやCSVデータをカード形式で閲覧・管理できるウェブアプリケーションです。


## 主な機能

* データをカード形式で表示
* 表示項目のカスタマイズ
* フィルターによる絞り込み
* カードの並べ替え
* JSON/CSVの読み込み・書き出し
* 自動保存（IndexedDB）
* バックアップと復元
